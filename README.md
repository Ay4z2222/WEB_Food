# 🥩 Mookata Buffet QR Ordering System
> ระบบสั่งอาหารบุฟเฟต์หมูกระทะแบบสแกน QR Code (Real-time Full-Stack Web Application)

ระบบบริหารจัดการร้านอาหารบุฟเฟต์หมูกระทะราคาเดียว รวมทุกอย่าง พร้อมฟังก์ชันสแกน QR Code สั่งอาหาร, ระบบจับเวลานับถอยหลัง 90 นาที, หน้าจอครัวแจ้งเตือนแบบ Real-time, ระบบเรียกบริการด่วน (ขอเติมถ่าน / เปลี่ยนกระทะ / เติมน้ำซุป) และระบบจัดการผังโต๊ะสำหรับแคชเชียร์

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 📱 หน้าจอลูกค้า (Customer Mobile Web)
* **ไม่ต้องโหลดแอป:** สแกน QR Code แล้วเปิดผ่าน Browser หรือ LINE ได้ทันที
* **ระบบจับเวลา 90 นาที (Server Timer):** นาฬิกานับถอยหลังยึดจากเวลาเซิร์ฟเวอร์จริง (ลูกค้าโกงเวลาไม่ได้)
* **ระบบแจ้งเตือน 15 นาทีสุดท้าย:** แถบเวลากะพริบเปลี่ยนเป็นสีส้ม/แดงเตือนให้สั่งรอบสุดท้าย และล็อคปุ่มสั่งอัตโนมัติเมื่อครบ 90 นาที
* **ป้ายแจ้งเตือนของหวานบริการตัวเอง:** ระบุชัดเจนว่าไอศกรีม 6 รส, รวมมิตรน้ำกะทิ และผลไม้ เดินตักเองได้ไม่อั้นที่บาร์ด้านหลังร้าน
* **ปุ่มบริการด่วน (Quick Service):** กดเรียกพนักงาน, ขอเติมถ่านไฟ, ขอเปลี่ยนกระทะ หรือขอเติมน้ำซุปได้ทันที
* **ตรวจสอบประวัติการสั่ง:** ลูกค้าดูสถานะได้ว่าอาหารจานไหนเสิร์ฟแล้ว หรือกำลังจัดของ

### 2. 🍳 หน้าจอห้องครัวและเตรียมของ (Kitchen Display System - KDS)
* **Real-time Order Updates:** ออเดอร์เด้งเข้าครัวทันทีผ่าน WebSocket (Socket.io)
* **เสียงกระดิ่งเตือน (Audio Chime):** ส่งเสียงแจ้งเตือนอัตโนมัติเมื่อมีออเดอร์ใหม่หรือมีคำขอบริการด่วน
* **แถบเตือนบริการเสริมเร่งด่วน:** แถบสีทองกะพริบแจ้งเตือนเมื่อมีโต๊ะขอถ่านหรือขอเปลี่ยนกระทะ พร้อมปุ่มกด "✓ จัดการแล้ว"
* **การ์ดออเดอร์คิวอาหาร:** แสดงเวลาที่ลูกค้ารอ และปุ่มเปลี่ยนสถานะ `กำลังจัดของ` -> `เสิร์ฟแล้ว`

### 3. 💻 หน้าจอแคชเชียร์ & ผังโต๊ะ (Cashier POS)
* **ผังโต๊ะ Real-time:** แสดงสถานะโต๊ะว่าง (สีเขียว) และโต๊ะที่กำลังรับประทาน (สีส้ม) พร้อมเวลานับถอยหลัง
* **Dynamic QR Code Token:** สร้างรหัสความปลอดภัยลับเฉพาะรอบ ป้องกันลูกค้าเดิมแอบกดสั่งอาหารเล่นจากที่บ้าน
* **ระบบจัดการสต็อกของหมด (Out-of-Stock Toggler):** สวิตช์ปิด-เปิดเมนูเมื่อวัตถุดิบหมด ซิงก์ไปล็อคที่มือถือของลูกค้าทุกเครื่องทันที
* **ระบบพิมพ์สลิป QR Code:** รองรับการพิมพ์รหัส QR ใส่เครื่องพิมพ์สลิปความร้อน (Thermal Printer)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** React 19, Tailwind CSS v4, Lucide React Icons, Canvas Confetti
* **Backend:** Node.js, Express 5, Socket.io (WebSocket Real-time Engine)
* **Build Tool:** Vite
* **Database:** JSON / File-based Database (รองรับการขยายเป็น PostgreSQL / Supabase)
* **Documentation:** Microsoft Word (`.docx`) พร้อมภาพประกอบและลูกศรชี้ระบุหน้าที่ทุกส่วนประกอบ

## 🚀 วิธีการติดตั้งและรันระบบ (Getting Started)

### 1. โคลน Repository
```bash
git clone https://github.com/Ay4z2222/WEB_Food.git
cd WEB_Food
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. รันระบบ (Development Mode)
เปิด Backend Server (Port 3001) และ Frontend (Port 5173):
```bash
# Terminal 1: รัน Backend Real-time Server
npm run server

# Terminal 2: รัน Frontend Dev Server
npm run dev
```

เปิด Browser ไปที่:
* **คอมพิวเตอร์หลัก:** `http://localhost:5173`
* **มือถือ (ในวง Wi-Fi เดียวกัน):** `http://<IP-เครื่องของคุณ>:5173`
